# 论文结构化复现

将已有实证研究转为审稿人能阅读、逐步运行并核对的复现资料。流程适用于不同研究主题、观察单位与识别方法；不预设变量、年份、滞后阶数、控制变量个数、固定效应或聚类层级。本技能设为显式调用。

## 先确定复现对象

读取本次指定的稿件、原始或整理后数据、现有代码及项目说明。没有指定稿件时，结合当前任务确定版本；只有在不同版本会实质改变结果且无法判断时才询问。不要仅按文件修改时间猜测。

把每张目标表及各列对应到数据、变量定义、样本筛选、估计方法、固定效应、权重、标准误和回归后统计量。区分“忠实复现既定模型”和“另作方法修正”：包装任务不授权新增识别策略、改样本以求显著或改写论文。实算与稿件冲突时保留真实结果，另列差异。

明确交付层级：仅从整理后的分析数据复现，还是包括原始数据清理。前者应说明输入的来源和构造，不能宣称已实现从原始数据到论文的完整复现。后者应保留必要的清理、匹配与构造代码。数据缺失时完成可做部分，并明确哪些表尚不能运行；不以模拟数据或旧系数补充实证结果。

## 按文章组织，而不是按软件步骤堆文件

用户给出的目录和范围优先。未指定时以文章实际章节为准，可采用以下四部分作为起点：

```text
交付目录/
  审稿人复现包/
    00_运行全部.R
    01_主回归和稳健性检验/
    02_内生性与识别检验/
    03_机制分析/
    04_进一步分析/
  复现结果/                 # 运行后按相同章节输出
  使用与核对说明.md
```

这些是可调整的目录类别，不是必须开展的分析。按实际章节增减、合并或改名；只请求某一部分时只交付该部分，不虚构IV、DID或机制。

- 章节子文件夹只放必要数据、代码和数据字典；默认用UTF-8 CSV与R。数据字典也可用CSV，长文字说明放包外。大数据或其他文件格式按实际需要处理。
- 表格、图片、日志、模型缓存和临时文件写到包外；默认不把开发过程、历史结果快照或大而无关的原始库塞进包中。
- 跨章节共用数据选择一个清晰的相对路径；小型章节专用数据可分别保存。避免多份来源不明、同名但内容不同的面板。
- 命名要能对应正文表、图及列。变量说明至少覆盖定义、单位、转换、来源和缺失编码。需要时保留事件清单、行业映射或空间关系等可核查输入。
- 未指定输出位置时在当前项目的`output`中新建有辨识度的版本目录；保留已有稿件和旧复现包。

## 代码以审稿人逐行可读为准

默认采用用户偏好的`data.table::fread` → `fixest` → `modelsummary`。写代码前读取[简明R写法](references/r-patterns.md)。

加载必要包后，第一项实质数据操作为`fread()`，只做必要、明确的整理，再直接写模型。每个模型独立命名，并在注释中写出对应表列、Y、核心X、控制、样本、固定效应、推断方法和必要单位。

- 对固定效应OLS、2SLS等适用模型使用`fixest`。不为统一接口把原有PPML、非线性模型或特定DID估计量偷换为OLS；保留目标估计量并解释必要的包。
- 回归公式显式列出变量。不要用自定义回归封装、公式字符串拼接、循环遍历模型组合或显著性筛选遮蔽模型。重复少量代码比隐藏设定更易核查。
- 聚合、bootstrap、空间加总等算法本身需要循环或函数时可以保留；说明作用并局限于必要步骤。主模型仍逐个列明。
- 根入口用有顺序的`source()`调用。相对路径、包版本、必要随机种子及运行顺序写明；不要求审稿人拥有本机其他目录或预先加载对象。安装依赖与正式回归分开。
- 原有滞后、分组、缩尾、权重和有效样本必须有可追溯定义。除非本次指定共同样本，不强行统一不同表的样本。

## 从本次模型导出表格

使用`modelsummary()`读取本次估计对象；描述统计可用其`datasummary`系列。表头、列序和变量标签对照目标稿件，必要时拆分过宽表。记录系数、正确标准误、观测数、固定效应、聚类口径以及该估计量适用的拟合和诊断统计量。

总体、组内、调整或伪R²分别标明，不强求所有估计量有同一种R²。小样本修正和自由度应与目标规格一致，不能因更换软件默认设置而无说明地变化。

遇到IV、DID、交互、分组或其他回归后统计量，按需要读取[估计与核验要点](references/estimator-checks.md)。不能用手工填写的旧系数冒充本次模型输出。必要的聚合统计量通过本次系数及协方差计算，并把算法留在代码中。

默认生成可离线打开的HTML；用户指定Word、LaTeX、CSV等则按其要求输出并检查。HTML可通过`tinytable`保存`modelsummary`生成的对象。不要只给图片形式的表格。

## 在交付前实际试跑

先核对数据单位、键、缺失、样本流失和变量构造，再运行全部承诺交付的回归及导表代码。对目标结果核对系数、SE、N、p值和拟合统计；解释差异属于舍入、统计口径还是实现错误。检查表格提取对象、列序、标签、脚注和显示是否一致。

将最终包复制或解压到独立目录，以新R进程从干净环境运行，确认不依赖本机绝对路径、旧缓存、包外私有输入或已加载对象。核对结果单元格；HTML随机ID不同不应当作数值差异。确认运行没有改写输入，也没有把结果写回数据子文件夹。对耗时或数据受限的未运行部分如实注明，不声称全部通过。

交付包外的简短说明应包含入口、依赖版本、输出位置、覆盖哪些表、已完成的核验，以及稿件需同步的差异和未完成项。按用户需要提供ZIP和结果导航；不为未请求的分析添加额外结果。最终答复直接给出路径、调用方式和影响结论的重要差异。
